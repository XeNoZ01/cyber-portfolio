## Technique

Site statique construit avec [Hugo](https://gohugo.io/) (thème sur mesure `themes/nc`), bilingue FR/EN, déployé sur GitHub Pages par GitHub Actions à chaque push sur `main`.

```
hugo server -D   # aperçu local, brouillons inclus
hugo --minify    # build de production
```
